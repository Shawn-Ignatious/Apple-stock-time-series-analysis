# Apple-stock-time-series-analysis

Installed Packages are
forecast ,tseries ,ggplot2 ,gridExtra
How to run my code
1.first step install the packages this is how you can do that;
install.packages(c("forecast","tseries","ggplot2","gridExtra"))

2. Step two is to load the packages after they have been installed by writing the following lines of code
library(forecast)
library(tseries)
library(ggplot2)
library(gridExtra)

3. the third step is to run everything and find the solutions as per request.
